# Computer Graphics Shaders

Shader-based assignments and the final project for CS 557.

## Summary
This folder collects the graphics work for the course, from small shader exercises to a final fractal scene.

## Tech Stack
- GLSL fragment and vertex shaders
- C++ and OpenGL-style rendering code
- Makefiles and command-line builds

## Contents
- HW1 — Step and edge blend elliptical dots
- HW2 — Noisy elliptical dots
- HW3A — Displacement mapping and lighting
- HW3B — Displacement mapping, bump mapping, and lighting
- HW4 — Cube mapping with reflective and refractive surfaces
- HW5 — Interactive magnify/whirl/mosaic effects
- HW6 — Snake shader effects
- HW7 — Twist effect
- Final — Fractal celestial shader scene

## Highlights
- GLSL fragment and vertex shader development
- Procedural patterns, lighting, and post-processing
- Interactive uniforms and keyboard-driven controls
- Fractal and SDF-based composition in the final project
